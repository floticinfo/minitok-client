AI-assisted coding needs more than generated diffs.

minitok turns a repository task into an inspectable workflow: research, plan, implement, verify, review, repair, and evidence.

It supports multiple LLM providers, keeps execution local-first, and leaves telemetry disabled by default unless users opt in. The demo and benchmark format focus on verification results and manual intervention counts rather than inflated speed or accuracy claims.

Learn more: https://minitok.dev/docs
Source: https://github.com/floticinfo/minitok
Install: https://www.npmjs.com/package/@flotic/minitok

```bash
npm install -g @flotic/minitok
minitok doctor
```

minitok is a paid workflow tool, not an AI model, and does not guarantee correctness or deployment outcomes.
